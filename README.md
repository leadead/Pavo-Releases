# Pavo

macOS 原生本地视频播放器：硬件加速播放 MP4 / M4V / MOV，打开视频时把同文件夹的视频按文件名顺序加入播放列表并连播。开箱即用，设置很少。

## 功能

- **硬件加速**：H.264、HEVC（含 10-bit、HDR）、ProRes，全部由系统硬件解码，占用低、省电
- **文件夹播放列表**：打开一个视频，同文件夹的视频自动加入列表并连播
- **简单操作**：滚轮调音量，方向键快进快退，双击全屏，空格或右键播放 / 暂停，⌘← ⌘→ 切换上一个 / 下一个
- **播放时置顶**、⌘⌫ **移到废纸篓**、可修改的**键盘快捷键**
- **画中画、AirPlay**，以及内嵌音轨和字幕切换
- **设置同步**：通过 iCloud Drive 在多台 Mac 间同步

界面支持简体中文、English、日本語、Tiếng Việt。

## 下载与安装

系统要求：macOS 26 及以上，Apple Silicon。

1. 下载 [Pavo.zip](https://github.com/leadead/Pavo-Releases/releases/latest/download/Pavo.zip)（[所有版本](https://github.com/leadead/Pavo-Releases/releases)）
2. 解压后把 Pavo 拖入「应用程序」

安装包已通过 Apple 公证。

## 更新

App 会自动检查更新，也可以在 Pavo 菜单中点「检查更新…」。

## 隐私

Pavo 不采集、不上传任何数据。
